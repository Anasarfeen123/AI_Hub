# Machine Learning

Machine learning is the study of algorithms that improve at a task from data rather than from explicit rules. This section covers the classical toolbox — the algorithms and practices that came before deep learning and that still power most tabular/business ML today, and that every deep learning method is built on conceptually.

- **[Introduction to ML](introduction.md)** — supervised vs. unsupervised learning, regression vs. classification, and the standard ML workflow.
- **[Algorithms](algorithms.md)** — decision trees, random forests, SVMs, clustering, dimensionality reduction, and when to reach for each one.
- **[Model Evaluation](evaluation.md)** — how to know if a model is actually good, not just accurate-looking.
- **[Projects](projects.md)** — beginner through advanced project ideas to practice the full ML workflow.

## Where this fits

If [Foundations](../foundations/index.md) taught you the math and code, this section teaches you to *do* machine learning: frame a problem, choose an algorithm, train it, and — critically — evaluate whether it actually works. Model evaluation is the part beginners skip and the part that separates a model that looks good in a notebook from one that works in production.

Once you're comfortable here, [Deep Learning](../deep-learning/index.md) extends the same workflow (data → model → loss → evaluation) to neural networks, which scale better on unstructured data like images, text, and audio.
