# Resource Library

A curated, cross-topic list of courses, books, papers, channels, and tools. Topic pages throughout this hub link to the specific resources most relevant to that page — this library is the consolidated version for browsing, and the place to add something that doesn't fit neatly under one topic.

Have a resource that belongs here? See [Contributing](../contribution.md) — resource additions are some of the easiest, most welcome pull requests.

## Courses

- [Andrew Ng — Machine Learning Specialization](https://www.coursera.org/specializations/machine-learning-introduction) (Coursera/DeepLearning.AI) — the standard ML starting point.
- [CS231n: Convolutional Neural Networks for Visual Recognition](http://cs231n.stanford.edu/) (Stanford) — computer vision, free lecture notes and assignments.
- [CS224n: Natural Language Processing with Deep Learning](http://web.stanford.edu/class/cs224n/) (Stanford) — NLP and transformers in depth.
- [fast.ai — Practical Deep Learning for Coders](https://course.fast.ai/) — code-first, gets you training real models fast.
- [Hugging Face — NLP Course](https://huggingface.co/learn/nlp-course), [LLM Course](https://huggingface.co/learn/llm-course), and [Computer Vision Course](https://huggingface.co/learn/computer-vision-course) — free, practical, library-first.
- [David Silver's Reinforcement Learning course](https://www.davidsilver.uk/teaching/) (DeepMind/UCL).
- [Google Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course) — free, concept-focused.
- [Kaggle Learn](https://www.kaggle.com/learn) — short, hands-on micro-courses across Python, Pandas, ML, and feature engineering.

## Books

- *Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow* — Aurélien Géron. The standard practical, code-first ML/DL reference.
- *Deep Learning* — Goodfellow, Bengio, Courville. The standard theoretical DL reference; [free online](https://www.deeplearningbook.org/).
- *Mathematics for Machine Learning* — Deisenroth, Faisal, Ong. Bridges math fundamentals directly to ML use cases.
- *Python for Data Analysis* — Wes McKinney. The Pandas/NumPy reference, written by Pandas' creator.
- *Practical Statistics for Data Scientists* — Bruce, Bruce, Gedeck.
- *Reinforcement Learning: An Introduction* — Sutton and Barto. The field's standard textbook; [free online](http://incompleteideas.net/book/the-book-2nd.html).

## Papers (foundational, read after the basics)

- ["Attention Is All You Need"](https://arxiv.org/abs/1706.03762) — the transformer.
- ["ImageNet Classification with Deep Convolutional Neural Networks"](https://papers.nips.cc/paper/4824-imagenet-classification-with-deep-convolutional-neural-networks) (AlexNet).
- ["Deep Residual Learning for Image Recognition"](https://arxiv.org/abs/1512.03385) (ResNet).
- ["BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding"](https://arxiv.org/abs/1810.04805).
- ["LoRA: Low-Rank Adaptation of Large Language Models"](https://arxiv.org/abs/2106.09685).

See [Research](../research/index.md) for how to find, read, and evaluate papers beyond this starter list.

## Datasets

- [Kaggle Datasets](https://www.kaggle.com/datasets) — broad, searchable, beginner-friendly.
- [Hugging Face Datasets](https://huggingface.co/datasets) — the standard hub for NLP/multimodal datasets.

## Frameworks & Tools

- [PyTorch](https://pytorch.org/) and [TensorFlow](https://www.tensorflow.org/) — the two dominant deep learning frameworks (see [Frameworks](../deep-learning/frameworks.md)).
- [scikit-learn](https://scikit-learn.org/) — the standard classical ML library.
- [Hugging Face `transformers`](https://huggingface.co/docs/transformers) — pretrained models and fine-tuning for NLP, vision, and multimodal tasks.
- [XGBoost](https://xgboost.readthedocs.io/) and [LightGBM](https://lightgbm.readthedocs.io/) — gradient boosting libraries for tabular data.
- [OpenCV](https://docs.opencv.org/) and [Ultralytics YOLO](https://docs.ultralytics.com/) — computer vision processing and object detection.
- [LangChain](https://python.langchain.com/) and [LlamaIndex](https://docs.llamaindex.ai/) — building RAG pipelines and LLM agents.
- [Gymnasium](https://gymnasium.farama.org/) — standard reinforcement learning environments.
- [Weights & Biases](https://wandb.ai/) and [TensorBoard](https://www.tensorflow.org/tensorboard) — experiment tracking.
- [Ollama](https://ollama.com/) — running open-weight LLMs locally.

## Competitions

- [Kaggle](https://www.kaggle.com/competitions) — the largest and most accessible ML competition platform, spanning tabular, vision, and NLP problems.
- [DrivenData](https://www.drivendata.org/) — competitions focused on social-impact applications of data science.
- [AIcrowd](https://www.aicrowd.com/) — research-oriented challenges, often tied to academic benchmarks.
- Conference-affiliated challenges (e.g. workshop competitions at NeurIPS/CVPR) — see [Research](../research/index.md) for how to find these.

## AI Tools

Tools that use AI to help you build, learn, and work — distinct from the ML *frameworks* above, which you use to build models yourself.

- [ChatGPT](https://chatgpt.com/) and [Claude](https://claude.ai/) — general-purpose assistants useful for explaining concepts, debugging, and drafting — verify anything technical against a primary source before relying on it.
- [GitHub Copilot](https://github.com/features/copilot) and [Cursor](https://www.cursor.com/) — AI-assisted coding directly in your editor.
- [NotebookLM](https://notebooklm.google/) — summarizing and querying a set of documents/papers you upload, useful when working through a stack of research papers (see [Research](../research/index.md)).
- [Perplexity](https://www.perplexity.ai/) — search-oriented AI assistant with cited sources, useful for fast literature/tool discovery.
- [Hugging Face Spaces](https://huggingface.co/spaces) — try out thousands of published models directly in the browser before deciding whether to integrate one into a project.
