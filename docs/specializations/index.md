# Specializations

Applied tracks that don't fit neatly into the core [Computer Vision](../computer-vision/index.md) / [NLP](../natural-language-processing/index.md) / [Generative AI](../generative-ai/index.md) / [Reinforcement Learning](../reinforcement-learning/index.md) split, but are common enough in practice — and interesting enough — to deserve their own pages.

- **[Time Series Forecasting](time-series-forecasting.md)** — predicting future values from time-ordered data: trend/seasonality decomposition, classical models (ARIMA, Prophet), and modern ML/deep learning approaches.
- **[Speech & Audio AI](speech-audio-ai.md)** — working with sound as input or output: speech recognition, text-to-speech, and audio classification.
- **[MLOps](mlops.md)** — experiment tracking, model versioning, CI/CD for ML, and monitoring a model once it's live.
- **[AI Deployment](ai-deployment.md)** — serving, containerizing, and optimizing models so they're actually reachable outside a notebook.

The first two build directly on [Deep Learning](../deep-learning/index.md) — expect the same CNN/transformer toolbox to reappear, just applied to a different kind of data. MLOps and AI Deployment build on [Model Evaluation](../machine-learning/evaluation.md) — they're about keeping a model correct and reachable *after* training, not training it in the first place. More specializations will be added here as the hub grows; if there's a track you think belongs, see [Contributing](../contribution.md).
