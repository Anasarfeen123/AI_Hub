# Contributing to the Hub

!!! info "Under construction"
    This page is a placeholder created during initial scaffolding. The full contribution guide — page templates, style conventions, and the PR workflow — is written as part of Phase 4 of this hub's build-out.

In the meantime, the short version:

1. Fork the repository and create a branch.
2. Add or edit a Markdown page under `docs/`.
3. Run `mkdocs serve` locally and check your page renders correctly.
4. Open a pull request describing what you added and why.
